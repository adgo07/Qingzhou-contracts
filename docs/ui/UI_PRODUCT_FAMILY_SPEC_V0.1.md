## 4. 首页与业务壳的落实

按 A-01～A-07 处理入口与壳切换。B 类推荐中间任务顺序：首页 → 标准库 → 对应新建业务 → 表格导入 → 对应记录 → 产品专属库；不额外锁定全部侧栏顺序。

### 4.1 本轮窗口与页面基准

首次启动使用非最大化窗口，在当前屏幕工作区居中；系统边框计入可用区约束。以后恢复本产品窗口大小、位置与最大化状态；显示器移除或布局变化后将窗口收回可用区。窗口状态属于本地 Presentation State，不改变业务数据恢复规则；启动仍到 A-01 的无侧栏首页。低屏幕允许缩小，正文可滚动，设置及主要动作始终可达。尺寸及约束方法见指南第 4 节。

首页设置置于右上，业务页设置置于侧栏底部。首页打开设置保留无侧栏上下文，业务页打开设置保留业务壳；设置用页面还是对话框可由产品选择。帮助、关于和最近工作按已有能力保留，不成为新增强制入口。

共同页面采用“页头标题 + 可选有用说明 + 固定动作区”，不为对齐塞空副标题。标准库保留 A-08 的五列及筛选工具行，详情采用三个连续区域；记录列表与独立详情为两个页面，详情保留 A-10 两页签，结果按业务分区可读，不暴露实现术语。已有分页或加载更多方式本轮保留，统一列表底部计数与控制区，所有记录可达，不为视觉统一改后端分页。表格导入四区标题采用“模板与说明 / 文件选择 / 数据预览与检查 / 处理结果”，按真实能力安排动作；禁用入口无需空页面。设置按实际能力分为应用信息、数据与备份、高级，不补造功能。

### 4.2 控件与动作基准

主、次、轻量、危险四种按钮角色保持一致的正常、hover、pressed、focus、disabled、busy 状态。组合禁用状态不能被主按钮样式覆盖；无选择时查看、删除禁用，无文件时处理禁用。忙碌时防止重复提交，结束或失败后按实际前置条件恢复。清除筛选不清除业务输入，刷新不丢未提交输入。

删除、替换、不保存采用明确中文动作按钮，取消作为安全出口；不为统一新增确认，不强改系统文件选择器。错误优先就近内联并可定位，确需阻断才弹窗。字段统一标签、单位、必填及必要说明，区分只读与禁用。保持 Decimal 文本精度，不为样式切换 QDoubleSpinBox 或截断小数，空白不等于 0。输入不吞键盘焦点，滚轮不意外改变下拉业务值，增删折叠不无故跳顶。

业务词保留“评价 / 分析 / 核算”，记录主词依第 2 节；有真实意义的批次记录保留。显示精度、窗口恢复和视觉反馈不改变正式判定、保存或审计规则。

### 4.3 状态展示基准

标准生命周期、软件支持、标准角色分开解释。生命周期候选展示词为“现行 / 尚未实施 / 已废止 / 已被替代 / 待核对”，必须逐项有证据映射；已被替代不等于已废止，缺实施日期不能凭空判为现行。证据不足时保留更准确的现有词并报告，不用批量替换制造误义。

软件支持采用三类展示值：“正式支持”须有本产品已批准范围、真实实现及适用验收证据，并遵循第 5 节的 Conformance 边界；“已实现，待验收”须有本产品实际实现证据，同时明确尚未完成所需验收，不构成正式支持；“未开放”须有本产品当前发布范围或能力边界依据。无法准确映射时保留更准确的现有词并报告，不将“已实现”与“待验收”拆成两个独立支持等级。“配套通则”是标准角色，不是软件支持程度。以上只是展示映射，不改变持久化枚举，不建立公共状态 Contract。未开放入口保持禁用并提供 tooltip，基础文案为“当前暂未开放”，有真实原因可追加。

### 4.4 品牌与实施范围

首页与侧栏使用同一正式透明 PNG 原图，等比展示并随各产品离线包分发；资产和来源见 [品牌资产说明](assets/README.md)，尺寸及 DPR 方法见指南。禁止拉伸、重绘品牌、AI 超分或反复放大已缩小位图，不要求 CDR 转 SVG。A-06 的 SVG 同义动作图标要求不用于强迫品牌位图矢量化。线性动作图标采用正式资产目录中从中央既有 15 个图形原样复制的基准，语义映射见资产说明，不重设计；未覆盖语义继续 OPEN。

本轮仅处理授权的 UI 范围，不迁移业务架构、不改变 Frozen Contract、platform-lock、算法、标准支持范围、正式记录 / 保存 / 审计规则；第 5 节的既有 Owner 授权与待迁移约束继续有效。

## 6. B 类推荐设计

在第 3～5 节行为边界内按业务复杂度组织页面。参数 / 因子库可采用搜索、列表、可读详情，编辑与版本能力依业务批准范围，不发明 Quantity / Unit 语义。新建可用单页分区或既有专业表单 / 页签，不将 A-15 变成强制五页签，不增加统一草稿或保存机制。具体尺寸和方法只在[指南](UI_DESIGN_GUIDELINES_V0.2.md)维护。
