## 4. 本轮实施核对

按规格第 4 节行为、指南第 4 节参数检查实际修改部分；未涉及项写 N/A，不重复全量审计。

- [ ] 使用独立临时用户配置启动，检查首次居中、非最大化、客户区目标与整窗可用区；重启检查大小 / 位置 / 最大化恢复，模拟掉屏后窗口可达。低于目标屏幕时正文滚动、设置与主要动作可达；业务恢复规则不变。
- [ ] 在相同窗口 / DPI 抽查首页、标准库或记录、新建、详情四个代表视图，核对侧栏、导航、单层边距、字体、最终外框、页签和按钮角色；不用 QSS 内容高度充当外框证据。增加一次高 DPI 抽查即可。
- [ ] 切换 normal / hover / pressed / focus / disabled / busy，检查 primary + disabled、无选择查看 / 删除、无文件处理、防重复提交与结束恢复；失败 / 取消后条件正确，中文动作明确，取消可安全退出。
- [ ] 输入高精度十进制文本及空白，编辑 / 失焦后核对业务值与文本精度；键盘焦点可见且尺寸不跳，滚动下拉不误改值；清除筛选、刷新、增删折叠后输入与滚动位置合理。
- [ ] 放入长中文和多行内容，调整列宽，核对行高与完整可读性；列表底部计数及既有分页 / 加载控件可达，能访问旧记录。
- [ ] 对本次涉及标准逐项核对生命周期、软件支持和标准角色的映射依据；替代与废止不混同，日期不足不凭空判现行，缺证据保留 OPEN；未开放入口禁用并有 tooltip。
- [ ] 核对首页和侧栏 Logo 使用正式原图、等比透明、逻辑宽度及 pixmap DPR；resize / 跨 DPI 后从原图重绘。离屏属性检查如实标明，不能替代人工多屏验收。
