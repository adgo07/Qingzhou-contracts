## 4. 真实能力与业务保护

- [ ] ECQuota Excel导入与折标系数库当前未开放，显示禁用，不提前开放。
- [ ] EquipEffi 不新增草稿、额外保存或重复确认；Excel 实现与独立验收状态分开记录。
- [ ] GHGTOOL Excel 只读预览、不自动建正式记录，工作区与正式记录分别管理。
- [ ] 查看记录使用保存时快照，不按最新标准包重算或漂移。
- [ ] 显示修约不回流正式判定，不改标准解释、Calculator 或 Numeric。
- [ ] 隐藏来源 / 审计区域不删除证据、追溯和历史数据，普通页面不泄露机器标识。
- [ ] 读取新指南不修改 lock，不声称 Frozen Contract adoption。
