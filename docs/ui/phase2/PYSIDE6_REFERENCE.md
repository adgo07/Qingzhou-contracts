# PySide6 实施参考

状态：**ACTIVE / EVOLVING**
用途：后续业务仓独立 UI 工作的映射建议。本文不是实施计划、公共 UI Contract、公共 PySide6 package，也不授权 Phase 3 或生产代码改动。

三个业务仓继续独立开发、安装、升级和离线运行。各仓可根据现有技术栈和需求采用、修改或拒绝本参考；不能从原型推导出三个产品已经迁移到 PySide6。

## 1. 架构边界

遵守 Architecture V2.1 的 Presentation → Application → Domain → Port/Repository → Infrastructure 分层。PySide6 控件、信号槽、对话框、当前页、选中行和表单临时值留在 Presentation 或产品现有应用层适配中；Domain/Application 不依赖 PySide6、控件属性、Qt currentIndex、绝对路径或桌面弹窗。

真实输入、校验、业务规则和 Calculator 仍归各产品现有业务层。UI 调用明确的应用服务，展示其业务结果和可读依据。不要复制 Calculator 到窗体，不要因视觉一致而引入混合多个 Domain 的 UniversalEngine。

## 2. 页面与控件映射建议

| 原型模式 | 可选 Qt Widgets 映射 | 实施注意 |
|---|---|---|
| 无侧栏首页、业务页带侧栏 | 主窗口布局和页面容器，按路由显示/隐藏导航容器 | 业务侧栏“首页”返回无侧栏首页；窄屏顶部水平导航为待确认建议；导航状态不写成业务 Contract |
| 标准库搜索和五列 | QLineEdit / QComboBox、QTableView、独立 table model | 搜索/显示不改变标准数据或软件支持状态 |
| 标准详情三个页签 | QTabWidget 或等价语义页签 | 恰好“基本信息 / 适用范围 / 标准要求”；无来源区域，保留原文操作 |
| 参数 / 因子库 | 搜索列表和只读 QDialog 详情 | 仅呈现产品已有能力；ECQuota 禁用、EquipEffi 不设独立库、GHGTOOL 详情只读 |
| 记录完整列表和详情 | QTableView / 分页控件、独立页面或详情对话框 | 所有记录可达；详情仅两页签；不加重开业务或审计详情 |
| Excel 四区 | 分区 QWidget / QGroupBox | 四区不强制为向导；处理动作依据产品真实能力 |
| 新建与长表单 | QScrollArea 和分区表单；动态排放源使用可增删行容器 | 五类功能不是五个强制页签；错误在数据检查区域展示，键盘焦点可达 |
| 设置推荐对话框 | Owner 确认后可选 QDialog | 首页设置承载尚未确认；确认前沿用各产品现有行为 |

排序、搜索和分页属于展示查询能力，应与权威数据模型隔离。大表格要保留完整访问能力，不依赖固定条数的静态控件内容。

## 3. 文件、记录和产品差异

文件操作使用产品已有的离线文件流程和本地路径处理。禁用入口需同步禁用关联按钮和可达操作，并提供易懂原因。ECQuota 的 Excel 导入及折标系数库当前未开放，保持禁用；原型存在演示界面不表示可以开放。

EquipEffi 已有 Excel 批量能力，后续 UI 只能接入该仓真实能力和已验收范围；原型 CSV 不是 Excel 解析或生产输出。EquipEffi 不新增草稿与额外保存。GHGTOOL Excel 保持只读预览且不自动生成正式记录；工作区和正式记录继续分别管理。

记录详情读取正式记录保存时的数据和结果，不按最新标准包或算法重算。隐藏可见来源/审计区域不删除底层来源、计算依据、快照、追溯和历史兼容数据。ECQuota 不增加报告导出入口，也不借此删除既有底层兼容或数据能力。

## 4. 数值和计算展示

演示原型不含权威计算。生产 UI 必须调用对应产品现有、已验收的应用/Domain 计算链路，并展示真实输入检查、结果和依据。不得把演示样例、固定输出或 UI 格式化逻辑当作正式计算。

显示修约只影响呈现，不回流正式比较或判定。Numeric Profile、Calculator 版本、标准解释、结果快照和业务存储结构保持原有权威实现；本轮不修改它们，也不提出新的公共字段或 Schema。

## 5. 交互和无障碍

使用明确标签、键盘 Tab 顺序和可见焦点；按当前原型方案，输入错误集中在数据检查区域展示。禁用态需解释原因。高 DPI 下图标和文字保持可读；表格在窄窗口保留访问方式，长表单可滚动。空态、无搜索结果、错误和长数据应基于产品真实数据与错误语义设计，不复制原型的模拟状态码。

本文只描述可能的技术映射。何时以及如何在任一业务仓实施，须由该仓独立任务确定范围，核对真实 UI 与产品治理并按要求验证；本轮不启动那些实施。
