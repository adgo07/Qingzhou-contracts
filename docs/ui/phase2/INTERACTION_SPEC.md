# 交互说明

状态：**ACTIVE / EVOLVING**。本文件描述 Phase 2 原型的演示行为；原型行为不构成产品批准或正式业务能力。

## 1. 范围与分类

- **A：Owner 当前决定**：依照 UI 指南 v0.2 / 产品家族规格 v0.1 的 A-01～A-16。Owner 后续可修改，并非永久冻结。
- **B：推荐方案**：本原型用于讨论的布局、承载方式、交互顺序和示例文案。可调整，不作业务仓实施门槛。
- **C：待开放或允许探索**：真实业务能力尚未开放或设计尚未确认；原型说明边界，不阻止未来评估。

原型在页面内存状态中模拟导航、筛选、表单、反馈和产品切换。刷新后重置，不持久化。演示数据在数据文件与页面标记中说明。

## 2. 导航与产品切换

启动后显示无侧栏首页。标准库位于新建业务之前，设置独立呈现，不混入主要业务入口组。首页设置采用独立对话框是 B 类推荐；是否采用及其侧栏行为为 OPEN。

进入业务页后显示左侧导航。导航顶部使用真实青舟 LOGO，底部独立显示设置；点击“首页”回到无侧栏首页。原型顶部可切换产品以对照家族共性，不表示生产软件提供软件间运行时切换。

| 产品 | 新建 | 记录 | 专属库 |
|---|---|---|---|
| ECQuota | 新建对标 | 对标记录 | 折标系数库（显示禁用） |
| EquipEffi | 新建分析 | 分析记录 | 无 |
| GHGTOOL | 新建核算 | 核算记录 | 参数与因子库 |

三个产品统一使用“标准库”和“表格导入”。未开放入口可见、禁用并说明原因，不能进入虚假可用流程。

## 3. 标准库

列表提供关键词搜索（标准编号、名称、适用对象）及标准状态筛选，不额外设置软件支持下拉框。五列标题按 Owner 当前确认内容展示：**标准编号、标准名称、标准状态、实施日期、软件支持**。标准状态与软件支持分列表达，不把“已收录”写成正式支持。演示搜索匹配编号或名称；状态筛选选项和值仅为演示，不建立公共状态枚举。

点击标准编号或标准名称均可进入同一个标准详情页面；详情在一页连续显示**基本信息、适用范围、标准要求**三个分区，取消标准详情页签。适用范围删除“软件支持范围”；详情不显示发布单位、标准关系或来源区域，保留查看标准原文；原型不附原文时须清楚提示。

状态筛选组合、默认排序、列宽和原文不可用时的最终文案仍开放。五列标题按当前 Owner 决定处理；产品家族规格中尚未同步的旧 OPEN-01 描述不在本任务内修改。

## 4. 业务记录

记录列表可搜索，展示完整演示集合并可分页或持续加载，不只显示最近几条。点击记录进入独立详情，严格只有两个页签：**基本信息与结果、输入数据与计算依据**。

演示内容标明是快照示例，不能称作真实历史记录或按当前标准包重算的结果。页面不提供基于记录重新开展业务、审计详情入口/页签/页面；ECQuota 不提供报告导出入口。

## 5. 表格导入

四个区域是统一信息结构建议，**不是四步强制向导**。原型建议标题为“模板与说明、文件选择、数据预览与检查、处理结果”；最终标题和动作编排为 OPEN。

| 产品 | 原型交互 | 必须显示的边界 |
|---|---|---|
| ECQuota | 入口和四区预览均禁用，不触发选择、解析或计算 | Excel 导入当前未开放；不伪造正式导入能力 |
| EquipEffi | 浏览批量处理演示；输出可下载的演示文本/CSV样例 | 不解析真实 XLSX，不替代已有批量能力验收，不增加草稿或额外保存 |
| GHGTOOL | 展示模板说明、只读预览和检查反馈 | 不自动创建正式记录，不称为正式导入或核算完成 |

在本轮检查的 GHGTOOL HEAD（ff15061d2d765dbff869a0b182af4432d09398bc）中，Excel 预览仍是只读且本身不写入 records；另有显式保存项目、之后由用户主动发起正式核算的路径。该项目核算链路不同于 Excel 预览，原型不模拟它，后续页面映射为 OPEN。

文件选择器只呈现交互。演示流程不得把用户选择的 Excel 当作已经由真实业务程序处理；如提供下载，只生成明确标注的演示文本/CSV。

## 6. 参数与因子库

ECQuota 折标系数库入口禁用。EquipEffi 不设独立参数库。GHGTOOL 显示参数与因子库只读演示，点击参数行打开只读详情对话框；搜索、详情只作用于演示数据，不提供编辑、导入或版本发布。这不代表 GHGTOOL 生产库的完整能力边界。

## 7. 新建业务与检查

新建页面按五类功能组织：**基本信息、业务数据、数据检查、计算、结果**。它们可以是页面分区或既有专业流程，不强制变成五页签、五步或相同表单。数据检查、计算与结果要精炼、少重复卡片和长篇提示。

GHGTOOL 演示突出长表单和动态排放源：可增加或移除排放源行；每行使用演示共通的名称、类别、数量、单位和备注字段，不宣称具备类别专属专业表单。切换类别时是否保留不适用字段的输入为 OPEN；原型临时行为只是演示决定，不是数据迁移规则。长表单可以滚动，操作后仍能识别当前区域。

输入错误在“数据检查”区域集中展示，页面级错误说明下一步；本原型不把错误提示放在字段旁。示例检查规则只验证演示场景必填项/格式，不代表真实标准门槛。计算动作只生成带“演示”标记的输出，不调用正式 Calculator、不判断标准符合性。

GHGTOOL 的工作区演示与正式记录演示集合分别保存在内存；保存工作区不生成正式记录，Excel 预览也不生成记录。EquipEffi 不增加草稿或单独保存步骤；演示结果直接进入演示记录集合并标记为示例。

## 8. 空、错误、禁用和长数据

原型提供场景切换或操作路径，覆盖空列表、无搜索结果、字段错误、禁用入口、长表格、长表单和窄窗口。切换只改变演示状态，不定义生产错误码或业务状态。错误、警告和信息沿用产品交付治理规则，不为演示发明阻断等级。

窗口测试通过调整浏览器视口宽度进行，不提供虚假的原型窗口控制器。宽屏使用左侧栏和表格；窄屏建议把侧栏切换为顶部水平导航，表格可横向滚动、长文本可换行，控件保持可见可操作。顶部导航是待确认的响应方案 OPEN，不是 Owner 已确认要求。

用户可见的标题、按钮、提示与状态尽量中文；品牌名、标准编号、计量单位及文件格式等必要外文可保留。
