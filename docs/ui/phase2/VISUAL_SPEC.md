# 视觉规范

状态：**ACTIVE / EVOLVING**
性质：本轮原型可调整的视觉提案，不是 Frozen Contract、设计锁定文件或三个业务仓的强制像素规格。

## 1. 视觉方向

采用专业、简洁、中文优先的桌面界面。以清楚的标题、表格和表单层级呈现任务；强调色用于主要动作和当前位置。状态同时使用文字、图标或形状，不单靠颜色传达。左侧导航使用淡蓝色，LOGO 位于顶部，设置入口独立位于底部。

原型使用用户提供的真实青舟 LOGO：**prototype/assets/qingzhou-logo.png**，不描摹或重绘；忽略素材目录中的名片图。统一 SVG 图标位于 **prototype/assets/icons.svg**，线宽和视觉重心保持一致，配以清楚的中文名称。图标是原型资源，不形成公共安装包或运行时依赖。

## 3. 字体、层级和间距

原型优先使用系统已有中文字体，建议回退顺序为 Microsoft YaHei UI、Microsoft YaHei、PingFang SC、Noto Sans CJK SC、Source Han Sans SC，最后回退到系统 sans-serif。不要求下载或在线加载字体。正文当前以 14 px 为起点；标题和辅助文本按层级变化，具体字号不冻结。

建议用稳定间距节奏组织标题、控件和内容块。表格密度、长表单和组件留白可按真实内容调整；不规定卡片尺寸、像素网格或固定页面高度。中英文、标准编号和长字段应允许换行或滚动，避免截掉重要信息。

## 4. 组件状态

- **主要动作**：强调色实底、明确动词；每个视图保持主次关系。
- **次要动作**：轻量边框或文字按钮，避免与主动作同权重。
- **选中状态**：通过背景、文字或边框变化表达，并保持对比。
- **禁用状态**：降低视觉强调、禁止操作并解释原因；不能只变灰而无说明。
- **错误/警告/信息**：文字说明与图形提示同时表达；错误贴近字段或相关区域。
- **键盘焦点**：清楚可见，保留键盘顺序和操作语义。
- **空状态**：说明无数据的原因或合适下一步；未开放功能不伪装成可编辑空页。

这些是原型和后续设计的推荐处理，不新增业务状态枚举或改变产品交付治理定义。

## 5. 表格、长页面与不同窗口

桌面宽屏优先保证表头、关键列和常用操作可扫读。标准库维持五列；记录列表可展示更多字段。窄视口建议将左侧栏转为顶部水平导航（待确认的响应方案 OPEN），并保留全部列表访问能力，通过横向滚动和列宽管理访问，不静默截断记录。超长值可换行，或在可访问详情中展示完整内容，具体方案视字段选择。

长表单使用页面滚动并保留区域标题；GHGTOOL 排放源增删后应让当前操作位置清楚可见。窄窗口需检查输入、按钮、错误说明和对话框不超出视口。可改为单列，但宽屏侧栏尺寸不必带入窄屏。

## 6. 待确认

色号、字体回退、字号比例、圆角、间距、侧栏宽度、响应断点、表格密度和组件形态均可调整。Owner 尚未逐项确认，不得称为 A 类决定或永久视觉系统。
