性质：设计提案与可交互原型；不是 UI Contract、生产 UI 或业务能力验收。

三个业务软件仍在持续开发。本目录用一个离线原型展示共同页面骨架与各产品现有能力边界，供设计评审和后续独立实施任务参考。颜色、字体、尺寸、布局和交互细节均可调整。Owner 决定依照当前适用的 [UI 指南 v0.2](../UI_DESIGN_GUIDELINES_V0.2.md) 与 [产品家族规格 v0.1](../UI_PRODUCT_FAMILY_SPEC_V0.1.md)，后续仍可由 Owner 修改。

## 离线打开

在文件管理器中打开 **prototype/index.html**，或将该文件拖入浏览器。原型使用相对路径加载资源，不需要本地服务器、网络、安装包或账号。不要将资源路径改成远程 URL。

| 文件 | 用途 |
|---|---|
| prototype/index.html | 原型入口，可通过 file:// 打开 |
| prototype/styles.css | 视觉样式和可调整的 CSS token |
| prototype/app.js | 页面切换、交互与演示状态 |
| prototype/data.js | 明确标注的演示数据 |
| prototype/assets/qingzhou-logo.png | 用户提供的真实青舟 LOGO，按原图使用 |
| prototype/assets/icons.svg | 原型统一 SVG 线性图标 |

原型状态只保存在页面内存中，刷新后重置；不写入浏览器本地存储、数据库或业务仓。它只用于视觉与交互评审，不表示三个产品已经实施这些页面。

## 页面范围

原型可切换 ECQuota、EquipEffi、GHGTOOL。首页无侧栏，标准库入口位于新建业务之前，设置独立。进入业务页后显示淡蓝色左侧导航；点击侧栏“首页”返回无侧栏首页。入口名遵循产品家族规格。

| 页面 | 共同结构 | 产品边界 |
|---|---|---|
| 标准库 | 关键词与状态筛选、五列列表、独立详情和三个指定页签 | 标准编号、标准名称、标准状态、实施日期、软件支持；筛选值不构成公共枚举 |
| 业务记录 | 搜索、完整可达列表、独立详情和两个指定页签 | 不提供审计详情或基于记录重新开展业务；ECQuota 不显示报告导出 |
| Excel导入 | 四个信息区域，不强制作为四步向导 | ECQuota 禁用；EquipEffi 为演示批处理交互；GHGTOOL 只读预览且不创建正式记录 |
| 参数 / 因子库 | 搜索、列表和可读详情的演示 | ECQuota 显示禁用入口；GHGTOOL 只读演示；EquipEffi 不设独立库 |
| 新建业务 | 基本信息、业务数据、数据检查、计算、结果五类内容 | 不强制五页签；GHGTOOL 展示可增删的动态排放源和长表单 |

## 演示数据与结果边界

标准、记录、参数、排放源和计算输出均为**演示数据**。演示结果不接入正式 Calculator，不代表标准解释、标准符合性或正式判定正确，不得用于真实业务结论。结果区应持续标明“演示结果，未接入正式算法，不可用于正式判定”。

各产品的演示不扩大真实能力：ECQuota 的 Excel 与折标系数库入口仍禁用；EquipEffi 不展示草稿或额外保存流程，批量输出仅为演示文本/CSV，不解析真实 Excel 工作簿；GHGTOOL 的 Excel 只读预览本身不写入正式记录；最新业务仓还支持显式保存项目后由用户主动发起正式核算。本原型只展示 Excel 只读预览，不模拟该项目核算路径，后续映射为 OPEN；工作区与正式记录仍分开，预览不自动创建记录。禁用入口表达当前状态，不构成永久禁止未来实现。
